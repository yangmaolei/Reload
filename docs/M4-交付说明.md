# M4 交付说明：识别率与体验（Material Design 3）

> 交付范围：Steam / Epic / GOG / Ubisoft / UWP 自动发现、可外部覆盖的路径规则库、探测模式、
> 封面、诊断页、便携模式，以及整套界面的 Material Design 3 重做。
>
> 结论：`dotnet build` 0 warning / 0 error；`dotnet test` **128/128 通过（62.6 s）**，
> 其中 M4 新增 23 个用例（10 个 Locator、7 个能力、6 条验收）。

---

## 1. 六块能力与落点

| 块 | 代码落点 | 关键实现 |
|---|---|---|
| 平台发现 | `Core/Locator/SteamLocator.cs`、`PlatformLocators.cs` | Steam：解析 `libraryfolders.vdf`（新旧两种格式）→ 各库 `appmanifest_*.acf` → 安装目录 + `userdata/<id>/<appid>/remote`；Epic：`Manifests/*.item` JSON；GOG：`GOG Games/*` + `goggame-*.info`；Ubisoft：`savegames/<userId>/<gameId>`；UWP：注册表包列表 → `Packages/<PFN>/SystemAppData/wgs` |
| 路径规则库 | `Core/Locator/SavePathRules.cs`、`MiniYaml.cs` | 内置 11 条规则（My Games / Documents / Saved Games / Roaming / LocalAppData / Unity / Unreal / RPG Maker / Ren'Py / GameMaker / 安装目录）；数据目录 `save-paths.yaml` 可按 id 覆盖或追加；首次启动写 `save-paths.sample.yaml` |
| 引擎识别 | `Core/Locator/EngineDetector.cs` | 看安装目录标志文件：`UnityPlayer.dll`、`Engine/`、`www/js/rpg_core.js`、`game/*.rpy`、`data.win` |
| 探测模式 | `Core/Probe/ProbeService.cs` | 记录候选根指纹（深度 ≤6、跳过 cache/temp/bin/logs/重解析点、上限 12 万文件）→ 玩游戏 → 对比 → 按新增/修改、存档扩展名、路径关键词打分，返回 Top 20 候选 |
| 封面 | `Core/Covers/CoverService.cs` + `Infrastructure/HttpCoverDownloader.cs` | Steam CDN 头图（纯数字 AppId），落盘 `covers/steam-<appid>.jpg`；无封面时 UI 用 MD3 色块 + 首字母 |
| 诊断 | `Core/Diagnostics/DiagnosticsService.cs` | 存储/队列/设备/远端 + 最近 200 条日志；导出 zip（`report.txt` / `logs.txt` / `diagnostics.json` / `README.txt`），自动脱敏用户名、数据目录、URL 凭据、password 字段 |
| 便携模式 | `Core/Configuration/AppPaths.cs` | exe 同级存在 `portable.flag` → 数据目录为 `<exe>/data`，`IsPortable=true`；UI 禁用开机自启并明确提示 |

## 2. 界面：Material Design 3

### 2.1 设计令牌（`Themes/Md3Tokens.xaml`）

- 完整 MD3 色彩角色：primary / secondary / tertiary / error / surface 五档容器 / outline / inverse，
  外加无障碍扩展角色 success、warning（MD3 本身没有）。
- 字体阶梯：Display / Headline / Title / Body / Label 共 12 级；图标字体 `Segoe Fluent Icons` + `Segoe MDL2 Assets` 回退。
- 形状：4 / 8 / 12 / 16 / 28；层次：两级阴影（卡片、悬浮窗）。

### 2.2 控件（`Themes/Md3Controls.xaml`）

- 按钮五型：filled / tonal / elevated / outlined / text，外加 danger、icon、FAB、窗口按钮；全部带 state layer（悬停 8% / 按下 14%）。
- 卡片三型：elevated / filled / outlined。
- 输入：filled text field（聚焦 2 px 主色底边）、多行、PasswordBox、CheckBox、Switch。
- 导航：rail（选中 pill + 图标着色）、chip/badge、细分隔线、细滚动条、进度条、DataGrid、ToolTip。

### 2.3 页面

| 页面 | 内容 |
|---|---|
| 游戏（卡片墙） | 搜索 + 扫描 + 添加；卡片含封面/首字母、平台、快照数、状态徽标（已同步/待上传/冲突/需重新定位/远端缺失/未备份）、上次备份时间；空状态引导 |
| 游戏详情 | 返回、封面、状态、立即备份/恢复/刷新；操作行（导出 zip、清理、重定位、冲突、探测、打开目录、删除）；左侧时间线（触发图标 + 文件数/大小 + 备注），右侧差异视图（+新增/~修改/-删除 + 体积变化） |
| 诊断 | 四个指标卡（快照 / 待上传 / 对象占用 / 数据库）、上传队列、运行环境、最近 200 条日志（按级别着色）、连接测试、导出诊断包 |
| 设置 | WebDAV（测试/保存/证书指纹）、自动化（开机自启 Switch、当前触发规则）、数据与设备、关于 |
| 首次向导 | 3 步：连接云端（可跳过）→ 扫描并勾选游戏 → 确认；步骤指示器 + 规则库提示 |
| 探测窗口 | 说明 → 开始/完成探测 → 候选列表（评分、变化数、示例文件、勾选） |
| 对话框 | 备注、恢复确认、冲突、重定位、手动添加、消息框全部改为 MD3 卡片/按钮 |

窗口声明 per-monitor v2 DPI，并在打开时按工作区收敛尺寸与位置（避免小屏/125% 下底部按钮被裁）。

## 4. 与规格的偏差（都已验证或明确说明）

1. **GOG 不解析 Galaxy SQLite**：改用 `goggame-*.info` + 目录扫描。Galaxy 的库表没有公开文档，版本间会变；
   目录扫描覆盖"已安装的游戏"，只在多账号/未安装场景少识别一些。文档里明确，后续可按需加只读解析。
2. **规则库不内置 Ludusavi manifest**：其数据源自 PCGamingWiki，许可证有非商用限制。改为"内置 11 条通用模板 +
   用户可覆盖的 YAML"，首次启动会写样例文件；这是合规优先的选择。
3. **Steam 云存档令牌**用 `%STEAMUSERDATA%`（机器级），后面直接跟 `<steamid>\<appid>\remote`。
   规格里的 `<SteamUserData>` / `<SteamAppId>` 是"游戏级"上下文，现有解析器没有游戏上下文；
   用机器级令牌 + 字面段同样能跨机展开，且不会猜路径。
4. **封面只接 Steam CDN**：公开、无需密钥、许可清晰；非 Steam 游戏用首字母色块。
   SteamGridDB 需要 API Key 且条款另议，未接入。
5. **状态徽标少"有远端更新 / 离线"**：下行导入是即时的（拿到就落库），没有"已发现但未下载"的中间态；
   离线状态目前用"待上传 + 上次错误"表达，未单独做徽标。
6. **Ubisoft 游戏名不可得**：目录只有数字 ID，命名为"Ubisoft 存档 &lt;id&gt;"，用户可在后续版本改名（当前无重命名 UI）。
