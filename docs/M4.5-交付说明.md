# M4.5 交付说明：更名 Reload、主题自定义、界面打磨

> 交付范围：应用更名 **Reload**（含数据迁移）、6 色 × 亮/暗/跟随系统的主题系统、
> 设置增强（自动化参数 + 全局排除）、应用图标、按钮图标补全与封面清晰度修正。
>
> 结论：`dotnet build` 0 warning / 0 error；`dotnet test` **135/135 通过**（M4.5 新增 7 个用例）。

## 1. 更名 Reload

| 项 | 实现 |
|---|---|
| 显示名 | 窗口标题、标题栏品牌、托盘 tooltip/气泡、向导、关于页 → "Reload"（去掉 M4 徽章，换成"游戏存档同步"副标题） |
| 程序集 | `AssemblyName=Reload`，发布产物 `Reload.exe`；命名空间保持 `GameSaveSync.*`（不影响用户） |
| 数据目录 | `%LOCALAPPDATA%\Reload`；启动时若旧目录存在且新目录不存在 → 整体 `Directory.Move`（同卷原子），失败不阻塞启动 |
| 开机自启 | 注册表值 `GameSaveSync` → `Reload`，写入前删除旧值避免双开 |
| 单实例 | Mutex 改为 `Local\Reload.SingleInstance` |
| 应用图标 | 程序化生成 7 尺寸（16–256）传统 BMP 条目 ICO：紫→青渐变圆角方块 + 白 R + 同步弧；嵌入为 `Assets/app.ico`（`ApplicationIcon` + EmbeddedResource），exe 图标、窗口 Icon、托盘共用 |

迁移有两条单测：整体搬移成功、新目录已存在时不覆盖。

## 2. 主题系统

- **色板数据在 Core**（`Core/Theming/ThemePalettes.cs`，纯 CLR `PaletteColor(A,R,G,B)`，不引 WPF）：
  - 每个 seed 提供 Primary/Secondary/Tertiary 四色组的亮/暗两套；
  - 中性色（Surface 五档 / Outline / Inverse / Error / Success / Warning）亮暗各一套，不随 seed 变。
- **App 侧 `ThemeService`**：`Install()` 把一个固定 ResourceDictionary 挂到 `Application.Resources.MergedDictionaries`，
  `Apply()` 时 Clear + 重填同一实例 → 全部 `DynamicResource` 引用即时换肤、无需重建视觉树。
- 163 处颜色引用由脚本批量 `StaticResource → DynamicResource`（14 个 XAML 文件）；形状/字体/样式仍走 Static。
- **持久化**：`settings` 表 `ui.theme.seed` / `ui.theme.mode`；`Install` 同步读取（避免与设置页首次 Load 竞态，
  初版曾异步加载导致色板勾选与实际主题短暂不一致，已修）。
- 跟随系统：读 `HKCU\...\Themes\Personalize\AppsUseLightTheme`。

设置页"外观"分区：6 个色块圆点（选中带勾 + 描边环）+ 三个 RadioButton（跟随系统/亮色/暗色），切换即存。

## 3. 设置增强

| 项 | 行为 |
|---|---|
| 触发时机 | 退出延迟 1–30s / 去抖 1–60s / 空闲间隔 5–60min，写入 `settings`；`SnapshotSchedulerOptions` 注册为工厂从设置读取（保存后**重启生效**，界面已注明） |
| 全局排除 | `settings.snapshot.global_excludes`，每行一个通配符，`#` 注释；`SnapshotService.CreateAsync` 每次快照现读并与每个存档根的排除叠加 → **下次快照立即生效**，无需重启 |
| 规则库 | 路径展示 + 数据目录打开按钮（M4 已有），集中于"数据与设备"卡 |

## 4. 界面打磨

- **20 个纯文字按钮补齐图标**（Segoe Fluent/MDL2）：扫描、添加、备份、恢复、清理、导出、重定位、冲突、打开目录、测试连接、保存、刷新、重试、诊断导出等（脚本按 Command/Content 定位批量改写）。
- 封面 `RenderOptions.BitmapScalingMode=HighQuality` + `UniformToFill`，消除 125% 缩放下位图重采样发糊。

- 设置页新增 MD3 Radio 样式（20px 圆环 + 10px 内圆点）。

## 附：M4.6（圆角化 + 在线功能）

在 M4.5 之后的一轮追加，回应"控件要圆角"和"联网查存档位置/自动获取海报"：

### 圆角化
- 文本框/密码框：MD3「filled」的"上圆下方纸片"样式（`CornerRadius=12,12,0,0` + 底边线）→ 改为**四角全圆**（`CornerRadius=10` + 四周 1px 边框，聚焦 2px primary）。
- 按钮：`Md3.ButtonTemplate` 的圆角原为 `CornerRadius="{TemplateBinding Tag}"`，而"浏览…"等按钮用 `Tag` 存数据 → 圆角失效变方。改为模板内固定 `CornerRadius="20"`，彻底解耦。

### 在线存档路径（`Core/Online/`）
- `PcGamingWikiParser`：解析 PCGamingWiki 的 `{{Game data/saves|...}}` / `{{Game data/config|...}}` 模板，
  用**深度匹配**处理 `{{p|...}}` 嵌套（朴素正则会截断），`{{p}}` 令牌只按**路径首段**替换（避免 `game` 误伤 `Games`），
  注册表项跳过、每用户 ID 占位替换成 `*`。
- `PcGamingWikiProvider`：MediaWiki API 搜索页面 → 取 wikitext → 解析；带浏览器 UA、10s 超时、失败静默返回空。
- 集成：AddGameWindow 新增「联网查询存档路径」按钮，结果以令牌形式填入目录列表（`CreateSaveRoot` 直接识别）。

### 海报
- `CoverService` 优先下载 `library_600x900.jpg`（Steam 竖版海报，免费无 key），失败回退 `header.jpg`；
  游戏列表加载后 `QueueCoverLoad` 后台自动拉取，失败回落首字母色块。

### 数据源可用性（重要）
- Steam CDN（`cdn.cloudflare.steamstatic.com`）本环境直连可用，已验证。
- PCGamingWiki 从**数据中心 IP 被 Cloudflare 拦截**（本开发环境无法实测），但桌面住宅 IP 通常可过；
  实现已带浏览器 UA，并有 10 个单测（解析 5 + provider 3 + 封面 URI 2）覆盖解析与降级路径，真实访问需在桌面验证。

### 测试
- 新增 `MOnlineTests` 10 个用例；全量 **145/145 通过**。
